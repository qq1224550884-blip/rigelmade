# 更新日志

本项目基于 [infinite-canvas](https://github.com/basketikun/infinite-canvas)（AGPL-3.0）二次开发，本文件仅记录商业分支的变更。

## Unreleased

- [修复] 上游已完成但原图传输中断时保留原任务，支持断点续传和继续取图，恢复过程不重新生图或重复扣积分。
- [优化] 同账号短时复用相同参考图上传，页面显示上传、上游等待及原图下载耗时；刷新后仍可查询未完成任务。

- [修复] 融合上游固定尺寸映射，统一 1K/2K/4K 选择、实际请求与积分档位，并校验下载原图像素，拒绝低分辨率结果冒充高分辨率。
- [优化] 局部编辑新增矩形框选、清晰选区及固定屏幕大小笔刷，支持缩放后准确绘制；选区合成保留生成分辨率。

- [新增] 涂鸦局部编辑可附加材质参考图；Image 2.5采用选区引导及原图局部合成，避免选区外随生成改变（待真实效果验收）。

## v1.0.0（2026-08-05）

- 新增：商业版初始发布
  - 账号体系：邮箱注册、密码哈希、会话令牌、管理员角色
  - 计费：积分流水、生成前预扣、失败自动退款、重复请求不重复扣费、按生成张数倍增扣费
  - 支付：微信支付 API V3 Native 下单与回调验签/解密
  - 套餐：体验包（¥9.9/650 积分）、工作室包（¥29.9/2400 积分）、专业包（¥99/9000 积分）
  - 模型积分价：gpt-image-2 50、nano-banana-2 65、nano-banana-fast 65、nano-banana-pro 80（积分/张）
- 安全：AI 渠道 API Key 改为服务端环境变量持有，前端不再直连第三方渠道
