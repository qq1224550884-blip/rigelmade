# 待用户试用

## v1.1.0 专业效果图工作台

- 顶部「批注改图」支持在干净底图框选并填写中文要求，也可选择或上传现成批注图；建立任务后先检查清单、图片用途、模型和分辨率，再生成。
- 默认批注改图采用自然融合；可选「锁定框选外内容」使用局部选区，框外沿用原图，超出框的新增物体会被截断。批注和选区随账号画布一起保存。
- 图片提示词面板可指定底图、批注、材质、结构、灯光、风格与物件用途并调整顺序；复制节点保留输入连接，单张重试保留用途与选区。
- 「对比」支持完整原图滑杆与并排查看，不调用 AI、不消耗积分。
- 「保存到账号」打包当前画布及全部原图；「账号画布」可在另一设备打开本地副本。需要主动保存最新版本，不是实时协作；另一设备已保存新版时拒绝覆盖。
- 浏览器测试已验证中文批注建任务、原图对比、空白设备恢复媒体与批注、旧版本冲突和窄屏入口；视觉效果与实际使用仍由佳哥验收。
- 画布缩小时使用单独的本地 WebP 预览；下载、对比、导出和生图仍用原图，缩略图不进入项目压缩包。

## GPT 模型与快速预览

- 原有 GPT 2.5 日常 Flare 仍是默认模型，新增 Sunburst 精修，沿用日常模型的 1K/2K/4K 固定积分价。
- 新增“快速预览（2K）”：同一案例两次实测约 22、26 秒，普通 Flare 约 30、34 秒；每组仅两次，不能保证所有任务都有相同速度。
- 快速预览仅支持一张输出、最多一张底图，使用 medium 质量；多参考图、涂鸦和 4K 请选日常或 Sunburst。底图会按 2K 范围处理，细节与材质由用户比较验收。
- 快速预览预扣 24 积分，按上游已结算美元费用 ×300 向上取整，单张最多扣 24 积分，差额自动退回；本次测试案例实际 7 积分。账单未结算或下载中断时保留原任务，继续取图不会重新生图。
