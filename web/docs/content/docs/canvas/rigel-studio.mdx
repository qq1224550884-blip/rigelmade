# 专业效果图工作台

## 按批注改图

1. 把干净底图导入画布，点击顶部「批注改图」。
2. 在图上拖出需要修改的区域，为每一处填写明确要求。也可选择画布中已有的批注图，或上传 PNG、JPG、WebP 批注图。
3. 检查修改清单；需要材质参考时，选择对应图片。
4. 点击「建立改图任务」，检查节点面板中的图片用途、顺序、模型和分辨率，再点击生成。

第一张始终是干净底图。点击生成后，工作台先读取批注中的中文、箭头、涂鸦和位置，形成逐项清单，再把清单和原图交给所选 GPT 或香蕉模型改图；不是只擦掉笔迹。读取不明确或失败时停止生图，本站积分退回，不自动换模型或重新付费提交。该步骤属于同一次生成任务，不单独扣分；读图会增加等待时间，进度区会明确显示。

生成时可展开「已读出…项修改」查看清单。结果保存后，选择结果图并打开「批注改图」，可查看读取记录，也可复制到修改清单继续调整；记录随本机与账号画布保存。读取正确不等于生成模型一定严格执行，树木数量、位置和地表边界仍需用原图对比验收。

材质参考只用于对应材质，框选文字直接进入修改指令，原图保持独立。默认让模型自然融合；勾选「锁定框选外内容」后，结果在选区外沿用原图，边缘只在框内过渡。框选需覆盖新增物体的完整范围，超出框的部分会被截断。上传批注图本身不自动生成局部蒙版。读取最多支持8张输入图，批注图尽量使用清晰原图；超过3600万像素时需先裁掉无关边框。

使用新框选时会生成独立的批注图；如需使用上传的批注图，请撤销全部新框选。每张底图最多保留 30 处框选。点击「保存批注」只保存位置与文字，不生图、不消耗积分。

批注图通常需要至少两张输入图。「快速预览」只支持单底图，请选择日常 Flare 或 Sunburst 精修。模型是否正确执行每处要求，需要查看实际结果验收。

## 参考图用途与顺序

图片节点提示词面板中可调整参考图顺序，并指定底图、批注、材质、结构、灯光、风格或物件用途。第一张为唯一底图。将其他图片指定为底图会自动移到第一张；生成与单张重试都会保留已提交的用途。

## 对比原图与结果

点击顶部「对比」，选择原图 A 与结果 B。滑杆对比适合检查相同构图的变化，并排查看适合比较不同方案。对比使用完整原图，不调用 AI、不消耗积分。

## 保存到账号与换电脑继续

本机画布仍自动保存到当前浏览器。点击「保存到账号」会把当前画布、批注、生成记录中的参考图和全部原图一起保存到登录账号。**编辑后需要再次点击保存到账号**，本功能不是实时多人协作。

在另一台电脑登录同一账号，打开「账号画布」并选择「打开副本」，即可在新设备恢复原图和节点。打开会创建本机副本，不覆盖本机尚未保存的项目。

如果另一台设备已经保存新版本，旧设备会提示版本冲突。请先导出本地内容，再打开账号最新副本，或通过本地「复制画布」另存当前方案。不要反复点击保存试图覆盖新版本。

单个画布最多 64MB，账号画布共 512MB。缺少原图或文件校验失败时，保存会明确报错。云端画布仅当前账号可读取；删除账号画布会一起删除该快照的云端原图，本机副本保留。

## 大图显示

画布缩小时会使用浏览器本地生成的 WebP 预览；放大查看、对比、下载、导出及生图参考仍使用原图。缩略图不进入项目文档或云端压缩包。
